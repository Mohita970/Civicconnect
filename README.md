# CivicConnect

## Online Complaint Management System for Municipal Services

CivicConnect is a web-based municipal complaint management system that allows citizens to submit, track and verify complaints while enabling administrators to manage and resolve them efficiently.

## Key Features

- Citizen Registration and Login
- Online Complaint Submission
- Complaint ID Based Tracking
- Complaint Status Updates
- Department-wise Complaint Handling
- Resolution Proof Upload
- Citizen Resolution Verification
- Complaint Heat Map
- Admin Dashboard
- Complaint Management

## Technology Stack

- HTML
- CSS
- PHP
- MySQL
- XAMPP

## Project Workflow

Citizen submits complaint  
→ Complaint assigned to relevant department  
→ Admin takes action  
→ Admin uploads resolution proof  
→ Citizen verifies the resolution  
→ Final resolution
